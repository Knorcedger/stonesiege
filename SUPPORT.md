# StoneSiege support

StoneSiege is currently an alpha maintained by a small team. Support is best-effort, but reproducible reports are taken seriously.

- For a gameplay or technical bug, use the [bug report form](https://github.com/Knorcedger/stonesiege/issues/new?template=bug_report.yml).
- For a feature or game-direction proposal, use the [feature request form](https://github.com/Knorcedger/stonesiege/issues/new?template=feature_request.yml).
- For a suspected vulnerability, leaked credential, store-account issue, or private information, follow [SECURITY.md](SECURITY.md) and email [support@flarmio.com](mailto:support@flarmio.com).
- For an installation problem, include the platform, build number, device/OS, reproduction steps, and a screenshot or recording where useful.

Do not send signing keys, passwords, access tokens, private player data, or sensitive diagnostics through a public issue.
