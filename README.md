# Bannerfall (working title)

A love letter to Age of Empires II — an original real-time strategy game for iOS and Android
(and the browser), with classic mechanics: villagers, resources, ages, counters, castles,
and story campaigns.

- **Engine**: custom deterministic simulation (TypeScript) + PixiJS WebGL renderer
- **Mobile**: Capacitor wrapper for iOS/Android; the same build runs in any browser
- **Modes**: Practice (skirmish vs bots) and Campaigns (first: *William Wallace — The Rising of Scotland*)
- **Art**: original stylized isometric pixel art, generated by our asset pipeline (`tools/assetgen`)

## Quick start

```bash
npm install
npm run dev        # play at http://localhost:5199
npm run test       # simulation & data tests
```

See `docs/GDD.md` for the game design and `docs/ARCHITECTURE.md` for how it's built.
Native build, signing, and store handoff instructions are in `docs/MOBILE.md`.
